# internet-speed-tester

Скрипт для измерения скорости интернета с вашего компьютера. Он последовательно
скачивает файл (например, тяжёлую картинку) по указанному URL заданное число
раз (по умолчанию 10), дожидаясь ответа на каждый запрос, а затем печатает:

- время каждого отдельного запроса и скорость по нему;
- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость скачивания в МБ/с (1 МБ = 10^6 байт).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
python speed_test.py <URL>
```

Пример:

```bash
python speed_test.py https://speed.hetzner.de/100MB.bin
```

Дополнительные параметры:

- `--count N` — количество запросов (по умолчанию 10);
- `--timeout SEC` — таймаут одного запроса в секундах (по умолчанию 30).

Пример с параметрами:

```bash
python speed_test.py https://speed.hetzner.de/100MB.bin --count 5 --timeout 15
```

## Пример вывода

```
Запрос 1/10: 100.00 МБ за 2.10 с (47.62 МБ/с)
Запрос 2/10: 100.00 МБ за 2.05 с (48.78 МБ/с)
...
--- Итог ---
Всего скачано: 1000.00 МБ
Среднее время запроса: 2.08 с
Средняя скорость скачивания: 48.10 МБ/с
```
